charts/wire-ingress: The Envoy proxy fleet created by this chart now defaults to 3 replicas with advisory node/availability-zone spread. Adds a default PDB (except if replicas is set to 1). Default `gateway.zoneAwareRouting.enabled` makes Envoy prefer backend pods in its own availability zone, cutting inter-AZ traffic cost on multi-zone clusters. New `gateway.annotations` and `gateway.infrastructure.labels`. See the wire-ingress README.
