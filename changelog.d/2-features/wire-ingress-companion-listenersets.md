charts/wire-ingress: New `gateway.allowedListenerNamespaces` admits ListenerSets of companion charts (e.g. step-certificates) from other namespaces to the chart's Gateway; the release namespace is always admitted. With `FIPS_202205_tls_profile`, the patch now also covers attached ListenerSets that have no `ClientTrafficPolicy`. The README recommends the `XDSNameSchemeV2` runtime flag on Envoy Gateway 1.9 (with `gateway.patchPolicies.xdsNameSchemeV2: true`), because legacy listener names depend on ListenerSet creation order. The README no longer marks the chart as not ready for production.
